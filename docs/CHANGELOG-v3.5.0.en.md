# MAC-WebOSTV 3.5.0

[Windows](../windows/README.en.md) · [Android/Termux](../android/README.en.md) · [Tiếng Việt](CHANGELOG-v3.5.0.md)

All models use one installation engine for startup, HOME, portable voice, debloat and privacy. No SK8000 name check selects a reduced feature set. Owner backup restoration remains TV-bound.

DangBro is removed from the root flow. Faultmanager runs first only after exact live compatibility checks. Reported success waits for Homebrew/root SSH instead of starting another exploit; genuine failure offers eligible upstream alternatives.

Dependency preflight checks Node, startup, hashing, tar and Luna tools. Source-bound static ARM32/ARM64 input/PTY adapters are verified by hash, ELF metadata and a live ABI test. Private BusyBox applet wrappers repair available missing tools without changing system interpreters.

The common installer now installs asynchronous boot hook 40, waits for boot/app readiness and launches once. HOME validates actual remote channels/compositor before interception; input failure does not disable startup. Native NLP feeds a portable Node voice router covering the sample commands and accented YouTube searches. The YouTube adapter is limited to pinned AdFree 0.5.3.

Setup includes reversible debloat, also available through menu 4 on Windows and Android; Rollback is menu 5. Only optional apps are processed. Known original lock states are journaled; unavailable lock state means close-only, reported explicitly. LGWS is installed alongside AdFree. Its audited 0.7.0 profile blocks ACR, ads and telemetry while preserving voice, ThinQ, QuickSet, casting, LAN, IPv6, SDP, updates and Content Store. Filtered project blocklist overlays address upstream SDP semantics and are removed during rollback.

Dock pointer layout reads are cached/coalesced per frame. Blur/shadow costs are reduced while retaining widgets and wallpapers.

Validation covers source, generated packages and simulated TV installation/recovery. This release has not physically validated cold boot, HOME/Back/pointer, recognition or FPS on **55UM7400PTA / 05.40.97**. “Installed” is deployment evidence; physical behavior and vendor APIs still require testing. For an already rooted TV choose **Already rooted**. Enable Homebrew SSH Server and uninstall the Developer Mode application before reboot after rooting.

## Menu 4 refresh — 2026-10-29

[Keep-nine profile](KEEP-NINE.md): enable the sample nine apps, lock/close other installed apps except essential system components/HDMI, report failed/missing apps, and reapply at boot. App lock history is saved with backups for recovery across multiple sessions. Full Setup/Restore retains its separate optional-app profile.

## Unified MAC-WebOSTV branding

Display names, guides, shell launcher and Windows/Android/Docs assets use MAC-WebOSTV. New Android caches use `~/.mac-webostv`; existing private backup/key state is discovered automatically. Refresh saved installer download commands when upgrading.
